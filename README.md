# ai-happy-01 — v3

Entry image: an old street violinist plays with his eyes closed and a huge
laugh while a little girl in a red dress twirls barefoot in a sunlit town
square, autumn leaves swirling around them and smiling onlookers at the
edges. A fresh, specific moment of shared joy — music made visible — with
no smiley-face shortcut.

`main.ts` (Node 22, standard library only) copies `entry.png` to
`/output/entry.png`. Run locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`entry.png` is a JPEG (1024x683, ~214 KB), inside the 1 MiB / 1024x1024 gate.
